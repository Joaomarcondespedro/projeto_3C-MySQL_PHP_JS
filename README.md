# Projeto 3C - PHP, MySQL & JavaScript

Este repositório contém a aplicação desenvolvida durante o curso de programação básica do **Instituto 3C**, com foco na integração prática entre **PHP**, **MySQL** e **JavaScript**.

O objetivo do projeto foi consolidar os fundamentos do desenvolvimento web *full-stack*, englobando a criação de interfaces dinâmicas, regras de negócio no backend e manipulação de banco de dados relacional.

---

**Tecnologias Utilizadas**

* **PHP:** Processamento no servidor e comunicação com o banco de dados.
* **MySQL:** Modelagem e persistência dos dados.
* **JavaScript:** Interatividade, manipulação do DOM e validações no frontend.
* **HTML5 & CSS3:** Estruturação e estilização da interface.

---

**Funcionalidades Principais**

* Conexão e manipulação do banco de dados MySQL via PHP.
* Operações de CRUD (Criar, Ler, Atualizar e Deletar registros).
* Formulários com validação e dinamismo em JavaScript.
* Interface web funcional para gerenciamento de dados.

---

**Pré-requisitos**

Para rodar este projeto localmente, você precisará de um ambiente de servidor local configurado:
* **XAMPP**, **WAMP** ou **Laragon** (com PHP e MySQL).
* **Git** (opcional, para clonagem).
* Navegador web atualizado.
